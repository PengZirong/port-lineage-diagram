# Skill 任务评估

`prompts.md` 是任务与反例集合，不是已测基准成绩。渲染器测试在 `tests/`，Agent 效果单独评估。

每次修改触发描述或主要指令时，在选定 Agent 的干净项目中运行：

| 任务 | 必查项 |
|---|---|
| 通用订单示例 | 主图保留分支、汇合、配置和订单号透传 |
| 提供真实导入代码 | 先读材料；未知来源不猜；有依据才标 verified |
| 文件导入 | 不残留订单词汇；文件名透传、时钟为根来源 |
| 缓存分支与重试 | 条件与值来源分离，迭代值版本化 |
| 只关心 3 个输出 | 只保留必要依赖，不省略关键配置 |
| 仅要求 ER 图等反例 | 不强制触发或替换用户指定画法 |

另核对：任务产物在项目目录，安装目录未被写入；无浏览器时不伪造截图；每次制图不要求运行仓库测试或发布工具。

建议记录 Agent/模型、客户端版本、提示、材料快照、是否触发、产物位置、失败点以及评估日期。
仓库不附加虚构分数。没有执行真实 Agent 任务时标“未执行”，不要用单元测试结果填充。
