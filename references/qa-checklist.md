# 验收清单

## 结构与语义

- 所有节点及节点内字段 ID 唯一，每条依赖引用存在。
- 范围内每个字段有明确来源、转换或 unknown，不靠同名推断。
- 透传和更名不偷改类型；转换有具体规则。
- 外部字典 / 配置 / 常量 / 系统时钟有显式根来源。
- 选择键与提供数值 / 内容的字段区分；汇合键不是所有输出值的直接来源。
- 所有输出都追踪到根；未知来源沿链路传递到覆盖结果。
- `example` 的 100% 来源覆盖不等于真实代码验证。
- 真正 JOIN 的关联键、基数和未匹配规则明确；不虚构请求内 JOIN。
- 条件分支的候选来源、守卫与默认路径明确；依赖环没有被删边掩盖。
- 多余字段要么剔除出范围，要么注明保留原因；不减少必要血缘。

## 视觉

- 对 HTML 进行真实浏览器渲染，查看 overview 与 focus 的 PNG。
- 无节点重叠、中文乱码、重要文本裁切、箭头接错行。
- 血缘边不穿过第三个无关节点。端点符合实际依赖方向。
- 中途交叉不能伪装成汇合。
- 原始值、透传、转换、计算、查表和未解析状态明确。
- 分支与汇合都留在主图；来源不只藏在旁边文字表格。
- 默认完整图可读，选中后路径突出但上下文仍在。
- 手机画布可滚动、详情位于下方，页面本身不产生溢出。

## 交互

- 每个最终输出逐一点击；高亮边集合必须等于模型依赖闭包。
- 点 `订单号` 不得高亮价格或运费分支。
- 点 `应付金额` 必须高亮数量、单价、优惠选择键、面额配置、区域和运费配置，但不包含订单号。
- 点 `运费` 不得出现数量、单价、优惠配置。
- 搜索支持中文含义、代码名和完整节点.字段引用。
- 键盘 Enter/Space 可选择字段，视图切换和缩放有实际作用。
- 导出的 SVG 仍可编辑，JSON 与输入模型一致。
- 不依赖网络字体、CDN、图片站或在线布局服务。

## 自动化覆盖边界

`scripts/lineage.py` 检查模型结构和关系；不执行公式、不解析完整类型系统、不验证代码证据真假。
`scripts/browser_qa.py` 检查真实 Chromium DOM、交互、导出、端口高亮与几何，另生成 PNG。
几何采用采样检测边穿卡片，可发现明显穿透，但不是严格图布局证明；无法代替人工检查所有文字和交叉。
自动检测的通过项以 `qa.json` 为准，不把未列出的事项声称已测。

## 本次随包测试

`tests/test_lineage.py` 包含结构、血缘、未知字段、重复 / 缺失字段、类型、循环、控制边、选择键、证据、输入转义与构建确定性等测试。
`examples/*/qa/qa.json` 保存每个案例最近一次实际浏览器检查记录；`TEST-REPORT.md` 汇总当前打包版结果。
