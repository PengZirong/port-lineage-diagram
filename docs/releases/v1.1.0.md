# Port Lineage Diagram v1.1.0

本版本发布已合并的 Skill 仓库结构重构：安装单元、用户文档、演示与维护工具分离。现有绘图构建器、查看器、浏览器检查脚本和两份示例模型保持不变。

## 主要变化

- 实际安装入口为 `skills/port-lineage-diagram/SKILL.md`，根目录不再保留重复 Skill。
- 指令改为可独立理解的工作流程，移除“第一种图”等原聊天上下文。
- 从用户项目调用随包脚本；任务模型、HTML、SVG 和截图写入项目目录，不写入 Skill 安装目录。
- README 提供 Skills CLI 安装与自然语言调用示例。
- 小型输入模型随 Skill 安装；完整演示移至 `docs/demos/`，维护者测试和 Agent 评估分别放入 `tests/`、`evals/`。
- 运行资源采用精简、确定性 ZIP 打包，完整截图和维护工具不再随 Skill 安装。

## 安装

```bash
# 当前项目
npx skills add PengZirong/port-lineage-diagram --skill port-lineage-diagram

# 全局安装
npx skills add PengZirong/port-lineage-diagram --skill port-lineage-diagram -g
```

也可下载本 Release 的 `port-lineage-diagram-v1.1.0.zip`，解压后将 `port-lineage-diagram/` 整个目录放入客户端支持的 skills 目录。
安装包内 `SKILL.md` 位于该目录根部；GitHub 自动提供的 Source code ZIP 则是完整仓库，两者用途不同。

## 升级注意

从源码直接调用时，脚本路径改为 `skills/port-lineage-diagram/scripts/lineage.py`，示例输入改为该 Skill 下的 `assets/examples/`。
旧版根目录 `scripts/` 和 `examples/` 路径不再使用。已有工作流 JSON 无需因本次目录调整而改写。
完整交互演示及截图继续在仓库 `docs/demos/` 中提供，不重复放入安装附件。

## 发布检查与边界

发布工作流先运行仓库回归测试与两份示例的严格构建，再创建版本标签和 Release；之后回下载 ZIP 与校验文件，与本地构建逐字节核对。
目录重构阶段的 38 项测试与浏览器验收详见 `docs/verification/skill-layout.md`；本次发布重新运行程序回归和严格构建，不将旧的浏览器截图记录冒充本次重新截图。
本次没有新增真实 Agent 自动触发或联网 Skills CLI 安装验证，也没有更改许可证授权。

## 附件

- `port-lineage-diagram-v1.1.0.zip`：精简 Skill 安装包。
- `SHA256SUMS`：安装包的 SHA-256 校验值。

历史 `v1.0.0` 标签、Release 和附件保持不变。

## 维护者发布入口

将版本写入 Skill 的 `metadata.version`，同时提交对应 `docs/releases/vX.Y.Z.md` 到 `main`，会触发 `.github/workflows/release.yml`；也支持在 Actions 中手动指定与当前检出内容一致的版本。
测试失败不创建新版本；已有标签指向其他提交或该版本已存在 Release 时停止，不移动标签、不覆盖附件。
